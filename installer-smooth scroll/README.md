# Conveyor Lite — Installer

## 📦 Download

Download both files and place them in the **same folder**:

1. `ConveyorLite.exe` — The application
2. `conveyor_config.json` — Required configuration file

## ⚡ Quick Start

1. Download both files above into a folder (e.g. `C:\ConveyorLite\`)
2. Double-click `ConveyorLite.exe`
3. The app will show a small window, then minimize to system tray after 3 seconds
4. Hold your modifier key(s) + scroll to pan through windows

## ⚠️ Important

- **Both files must be in the same directory** — the EXE will crash without the config
- Edit `conveyor_config.json` to customize keybinds and behavior
- Changes are hot-reloaded (no restart needed)

## 🔧 Default Keybinds

| Action | Keys |
|--------|------|
| Activate hyperscroll | `Win + Alt` + Scroll |
| Resize window 25/50/75/100% | `Alt` + `1/2/3/4` |
| Swap window left/right | Modifier + `,` / `.` |
